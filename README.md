# Hand Gesture Music

ระบบรู้จำท่าทางมือสำหรับควบคุม Apple Music บน Windows งานวิชา AI/ML กำหนดส่ง 8 ตุลาคม 2026 และเดโมประมาณ 5 นาที ใช้ MediaPipe สกัดพิกัดมือ แล้วฝึกตัวจำแนกจากข้อมูลท่ามือของผู้ใช้เอง ท่าเหล่านี้เป็นท่าที่กำหนดเอง

## คำสั่งและพฤติกรรม

| ท่า | คำสั่ง |
|---|---|
| กำมือ | เล่น / พัก |
| นิ้วชี้และนิ้วกลางเป็น V | เพลงถัดไป |
| ชูนิ้วโป้ง | เพลงก่อนหน้า |
| ท่าอื่นที่เก็บเป็น neutral / ไม่เห็นมือ | ไม่สั่งงาน |

ยืนยันท่า 0.6 วินาที ค้างมือจะไม่สั่งซ้ำ ต้องปล่อยท่า 0.35 วินาทีก่อนสั่งใหม่ รุ่นล่าสุดรับสองมือและติดตามมือสั่งงานด้วยกรอบสีเขียว หากสองมือสั่งต่างกันจะรอ คำสั่งที่ยืนยันระหว่างตรวจเพลงเข้าคิว ไม่ถูกทิ้ง

## ใช้งานจากเครื่องเดิม

โปรเจกต์หลักในเครื่องอยู่ที่ `D:\hand-gesture-music` มีข้อมูลดิบ โมเดล และสภาพแวดล้อม Python อยู่ครบ ส่วน repository บน GitHub ไม่เก็บข้อมูลมือ โมเดล ไฟล์ติดตั้ง หรือบันทึกเพลงส่วนตัว

1. เปิด Apple Music และเลือกคิวหลายเพลง
2. เปิด `outputs/เปิดระบบควบคุมเพลง.cmd` เริ่มจากโหมดดูผลและลองท่า
3. กดเริ่มควบคุม แล้วเอามือออกก่อนเริ่มทำท่า
4. กดพักการควบคุมเพื่อกลับโหมดดูผล

ดู [คู่มือกล้องสด](outputs/LIVE_GUIDE_TH.md) และ [การปรับจากผลลองจริง](outputs/LIVE_FIXES_TH.md)

หาก Apple Music โหลด Home ไม่ได้และข้ามเพลงเอง ดู [ผลตรวจและการกู้ Apple Music](docs/APPLE_MUSIC_RECOVERY_TH.md)

## ติดตั้งบนเครื่องใหม่

ใช้ Windows และ Python 3.11 x64 เปิด PowerShell ที่โฟลเดอร์ repository แล้วเรียก `./setup.ps1` สคริปต์จะสร้าง `.venv` ติดตั้งรุ่นตาม `requirements.txt` และดาวน์โหลดโมเดลสกัดมือจากแหล่งทางการของ MediaPipe โดยตรวจ SHA-256 โมเดลนี้เป็นตัวสกัดตำแหน่งมือ ไม่ใช่ตัวจำแนกท่าคำสั่งที่ฝึกเอง

เมื่อ clone ใหม่ยังไม่มีข้อมูลผู้ใช้หรือตัวจำแนกที่ฝึกแล้ว ต้องเก็บข้อมูลด้วย `outputs/เปิดกล้องเก็บข้อมูล.cmd` และฝึกก่อนเปิดกล้องเดโม หรือนำ artifacts ของตัวเองกลับจากการสำรองในเครื่อง

ข้อมูลจริงอยู่ที่ `outputs/data/raw/<session_id>/` แยกทั้งรอบเป็น train/validation/test เก็บพิกัด ไม่เก็บภาพหรือเสียง ยืนยันข้างมือจริงใน `outputs/hand_verification.json` ตามตัวอย่าง `docs/hand_verification.example.json` แล้วรัน:

```powershell
./.venv/Scripts/python.exe tools/audit_data.py
./.venv/Scripts/python.exe outputs/train_gestures.py
```

## ผลและขอบเขต

โมเดลรุ่นแรกเลือก Logistic Regression C=1 จาก validation: train 1,893, validation 633, test 634 เฟรม ชุด test จำแนกถูก 634/634 ในสภาพที่เก็บจากผู้ใช้คนเดียว เฟรมภายในแต่ละช่วงสัมพันธ์กัน จึงไม่ใช่หลักฐานว่าใช้ได้ทุกคนหรือสั่งเพลงจริงถูกทุกครั้ง

ผลลองสดพบว่าโป้ง+ชี้+กลางอาจถูกอ่านเป็น V เปิดใช้รุ่นแก้สามนิ้ว Joint Logistic C=1 threshold 0.8 แล้ว ชุด test สามนิ้วหลายมุมใหม่ 233 เฟรมไม่อ่านเป็นคำสั่ง ส่วน replay คลิป test ไม่มีคำสั่งผิด การลองสดรุ่นใหม่นี้ยังต้องทดสอบ ดูผลและขั้นตอนใน [บันทึกการแก้สามนิ้ว](docs/THREE_FINGER_REVISION_TH.md) คะแนน test เดิมเป็นผลรุ่นแรก เก็บไว้และไม่ใช้เพื่อเลือกการปรับรุ่นต่อไป

รายงาน: [ผลโมเดลรุ่นแรก](docs/MODEL_REPORT_V1_TH.md), [ผลตรวจข้อมูล](outputs/DATA_AUDIT_TH.md), [การเชื่อมต่อเครื่องเล่น](outputs/CONNECTION_TEST_TH.md)

## ประวัติ Git

เริ่มใช้ Git หลังสร้างและทดลองระบบแล้ว commit ชุดแรกจัดแยกตามส่วนงานจาก snapshot ที่มีอยู่ ไม่ใช่ประวัติการพัฒนาที่บันทึกในเวลาที่ทำแต่ละขั้น วันที่ commit เป็นวันที่จัด repository จริง การเปลี่ยนต่อไปจะ commit ตามการแก้แต่ละครั้ง

ข้อมูลดิบและโมเดลเดิมเก็บในเครื่อง และไม่เกี่ยวข้องกับโปรเจกต์ PM2.5 ที่แยกต่างหาก
