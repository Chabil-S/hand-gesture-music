# ปรับจากการทดลองกล้องสด 4 ตุลาคม 2026

## เห็นสองมือในภาพ

รุ่นเดิมตัดทิ้งทุกเฟรมที่เห็นสองมือ รุ่นใหม่จำแนกมือทั้งสองแยกกัน แล้วเลือกมือสั่งงานและติดตามตำแหน่งข้อมือ กรอบสีเขียวบอกมือที่รับคำสั่ง อีกมือที่พักอยู่จึงไม่หยุดการทำงาน

หากสองมือทำคำสั่งต่างกัน จะรอให้เหลือคำสั่งเดียว ไม่เดาเจตนาผู้ใช้ หากสองมือทำคำสั่งเดียวกัน ระบบเลือกมือหนึ่งและสั่งเพียงครั้งเดียว การสลับลำดับมือที่ตัวตรวจส่งกลับไม่ทำให้ระบบลืมมือเดิมในกรณีที่ตำแหน่งยังติดตามได้

นี่เป็นการติดตามจากตำแหน่ง ไม่ใช่การยืนยันตัวตนของมือ เมื่อไขว้มือ มือบังกัน หรือมีหลายคนอยู่ใกล้กัน อาจจับคู่ผิดได้ ตัวตรวจตั้งให้เห็นไม่เกินสองมือ จึงยังไม่รองรับกลุ่มคนจำนวนมากอย่างแน่นอน

ยังควรทดลอง ณ จุดเดโมก่อนเริ่ม ใช้แสงเพียงพอและไม่ให้มือบังกัน โดยไม่จำเป็นต้องบังคับให้มีมือเดียวตลอดเวลา ไม่รับรองว่าจะใช้ได้ในทุก environment ที่ไม่เคยทดสอบ

## ไม่พลาดท่าระหว่างตรวจเพลง

สาเหตุเดิมอยู่ในส่วนควบคุม: รอตรวจเพลง 4 ครั้ง ครั้งละ 0.75 วินาที รวมประมาณ 3 วินาที และแทนทั้งคำสั่งและการปล่อยมือด้วย uncertain ระหว่างรอ

รุ่นใหม่รับท่าและการปล่อยมืออยู่ตลอด คำสั่งที่ยืนยันแล้วเข้าคิวและส่งทีละคำสั่งตามลำดับ ตรวจผลทุกประมาณ 0.08 วินาทีและจบทันทีเมื่อพบผล หากช้าจะรอไม่เกินประมาณ 1.5 วินาทีในช่วงตรวจผล (การเรียก API และการเตรียมคำสั่งอาจใช้เวลาเพิ่ม)

ทดสอบ API เล่นและพักจริงสองครั้ง ได้สถานะเปลี่ยนตามคำสั่งและ elapsed_seconds 0.125 ทั้งสองครั้ง บันทึกใน connection_events.jsonl ผลนี้เป็นเวลาของคำสั่ง API พร้อมตรวจสถานะ ไม่รวมคงท่า 0.6 วินาที เวลาในคิว หรือความหน่วงเสียงลำโพง

คิวรับรอได้ 3 คำสั่ง หากเต็มจะแจ้งว่าไม่รับคำสั่งนั้น เมื่อกดพัก คำสั่งที่ยังไม่ส่งจะถูกยกเลิก คำสั่งที่ส่งถึงเครื่องเล่นไปแล้วอาจยังเสร็จภายหลัง ไม่มีการส่งซ้ำอัตโนมัติเมื่อเกิดข้อผิดพลาด

## สามนิ้วถูกอ่านเป็น V

โมเดลเดิมฝึกเพียงสี่กลุ่ม และ neutral ยังไม่มีโป้ง+ชี้+กลาง จึงสามารถจัดท่าที่ไม่เคยเห็นเป็น next ด้วยคะแนนสูงได้ คะแนน test 100% รุ่นเดิมไม่ครอบคลุมความผิดพลาดนี้

ลองตัวกรองรูปทรงนิ้วโป้งแล้ว แต่ตรวจ train/validation พบว่าตัดท่า V จริงหลายเฟรมด้วย จึงปิดตัวกรองนี้ไว้ ไม่แก้ test เดิมหรืออ้างว่าปัญหาสามนิ้วจบแล้ว

วิธีแก้ด้วยข้อมูล: เก็บโป้ง+ชี้+กลางเป็น neutral เพิ่ม โดยแบ่งตามรอบ train/validation/test ใหม่ ดูขั้นตอนด้านล่าง ผล test เดิมเก็บไว้เป็นผลรุ่นแรก หลังปรับโมเดลต้องรายงานชุดสามนิ้วที่เก็บใหม่แยก และใช้ test เดิมเป็นการตรวจย้อนหลัง ไม่เรียกว่าชุดที่ไม่เคยเห็นผลมาก่อนอีกครั้ง

## เก็บท่าสามนิ้วเพิ่ม (ประมาณ 2 นาที)

1. ปิดหน้ากล้องเดโมเพื่อปล่อยกล้อง แล้วเปิด `collect_three_finger.cmd`
2. เริ่มมือขวา ชูโป้ง ชี้ กลางพร้อมกัน กดบันทึก 12 วินาที พลิกหน้ามือ/หลังมือช้า ๆ โดยคงสามนิ้ว ทำ 3 รอบ เปลี่ยนระยะหรือมุมเล็กน้อยระหว่างรอบ
3. เมื่อครบ กด “เริ่มชุดใหม่สำหรับอีกข้าง” ตรวจว่าหน้าจอเลือกซ้าย ใช้มือซ้ายทำแบบเดียวกันอีก 3 รอบ
4. ครบทั้งสองข้างแล้วแจ้งในแชทเพื่อให้ตรวจข้อมูลและฝึกใหม่ ไม่ต้องถ่าย 20 ช่วงเดิมซ้ำ

ข้อมูลเดิมไม่ถูกแก้ ชุดเพิ่มเป็น session แยกและใช้ป้าย neutral ไม่ใช่คลาสคำสั่งใหม่

## สิ่งที่ตรวจผ่านและที่ยังต้องลอง

ตรวจอัตโนมัติผ่าน: การติดตามเมื่อลำดับมือสลับ สองมือสั่งขัดกัน สองมือสั่งเหมือนกัน การยืนยันครั้งเดียวขณะค้างท่า การรับและปล่อยท่าระหว่างคำสั่งก่อนหน้ารอ การส่งตามลำดับ การยกเลิกคำสั่งที่ยังไม่ส่ง และการแยกรอบของข้อมูลเสริม

ต้องลองกล้องสด: มือหนึ่งกำมือ อีกมือแบหรือพัก; ปล่อยแล้วกำซ้ำ; สองมือทำคำสั่งต่างกัน; มือเคลื่อนผ่านกัน; และหลังฝึกใหม่ต้องทดสอบสามนิ้วทั้งสองข้าง คะแนนการสั่งเพลงจริงยังไม่ได้ประเมินครบทุกกรณี
