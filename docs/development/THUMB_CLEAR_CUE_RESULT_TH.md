# ผลทวนชูโป้งหลังปรับข้อความตามช่วง

ตรวจครบทั้งสอง session ล่าสุด 20261005_201043_126e6c71 และ 20261005_201138_bbbc563e รวม 1,217 เฟรม รุ่นทดลอง 20261005_194641 เกณฑ์ 0.8 แฮชตรงกับรุ่นที่ตรึงก่อนทดสอบ เปรียบเทียบกับรุ่นเก่า 171415 เกณฑ์ 0.6 และรุ่นใช้งาน 221121 เกณฑ์ 0.8 จากภาพเดียวกัน ข้อมูลทั้งสองรอบยังอยู่ครบ ไม่เลือกเฉพาะรอบที่คะแนนดีที่สุด

รุ่นใช้งานพลาดชูโป้งซ้ายครั้งแรกในรอบแรก และขวาครั้งแรกในรอบสอง รุ่นทดลองได้ครบ ข้อมูลรอบนี้สนับสนุนว่ารุ่นทดลองรับชูโป้งได้ดีขึ้นเมื่อเทียบกับรุ่นใช้งานจากภาพเดียวกัน ไม่สรุปว่าเหนือกว่าทุกมุมหรือทุกสภาพแสง รุ่นเก่าก็รับครบ แต่ก่อนหน้ายังส่ง next ผิดจากสามนิ้ว จึงไม่เลือกจากชูโป้งอย่างเดียว

รวมรุ่นทดลอง 374/389 เฟรม (96.1%) ตรงป้ายชูโป้งในช่วง hold ที่กำหนด เทียบรุ่นใช้งาน 228/389 (58.6%) ไม่ใช่ความแม่นท่าจริงที่ติดป้ายรายเฟรมและไม่ถือว่าเฟรมทั้งหมดเป็นการทดลองอิสระ ช่วงปล่อยหลังตัดเวลาเปลี่ยนท่าแล้ว รุ่นทดลองเป็น neutral 252/252 เฟรม ไม่มีการล็อกจนพลาดคำสั่งถัดไป

เวลาออกคำสั่งรวมเวลาที่ผู้ใช้เปลี่ยนท่า ไม่ใช่เวลาประมวลผลโมเดล รุ่นทดลองสองคำสั่งของมือซ้ายรอบแรกใช้ 1.531 และ 1.938 วินาทีหลังสัญญาณ hold จึงไม่อ้างว่าทุกคำสั่งสดเร็วกว่า 1.5 วินาที แม้ส่งครบ

## เวลาหน้าจอและกล้อง

บันทึกอายุภาพ ณ เริ่มรอบประมวลผลค่ากลาง 0.016 วินาที สูงสุด 0.062 วินาทีในรอบแรก และ 0.047 วินาทีในรอบสอง มี phase หน้าจอกับ phase ภาพต่างกันเพียง 2 และ 3 เฟรมตรงขอบเปลี่ยนช่วง ไม่มีความต่างระดับหลายวินาทีที่อธิบายอาการรอบก่อนด้วยบันทึกสองรอบนี้ ข้อมูลนี้ไม่ได้วัดเวลาที่หน้าจอวาดเสร็จจริงหรือเวลา inference

หลังข้อความใหญ่เปลี่ยนเป็นการกระทำของแต่ละช่วง ไม่พบรูปแบบคำสั่งชูโป้งไปออกใน release เหมือนรอบก่อน เป็นการสังเกตหลังแก้ UI ไม่ใช่การพิสูจน์เชิงสาเหตุ และไม่เปลี่ยนป้ายรอบก่อนให้เป็นผู้ใช้ทำผิด รอบก่อนที่ผู้ใช้ยืนยันทำตามจอยังคงบันทึกว่าเหตุไม่ทราบแน่ชัด

## สถานะ

ผลสดชูโป้งสองรอบนี้ผ่านจำนวนคำสั่งและการปล่อย รุ่นทดลองยังเป็น diagnostic-only เพราะ validation ชูโป้งขวาเดิม 142/158 (89.9%) ต่ำกว่าเป้าหมาย 95% ไม่แก้เกณฑ์ ไม่เปิด test ไม่ฝึกด้วยข้อมูลสด ไม่เปลี่ยนรุ่นควบคุมเพลง ไม่ขอถ่ายเพิ่มในขั้นนี้ การตรวจสดครั้งนี้ไม่มีคำสั่งไปยัง Apple Music จึงยังไม่ใช่หลักฐานการควบคุมเพลงจริงครบระบบของรุ่นทดลอง

ผลก่อนหน้านี้ของรุ่นเดียวกัน: กำมือและ V ส่งถูกครบ 8/8 ครั้งในการทดสอบเต็มรอบ และ neutral/สามนิ้วทั้งสองมือไม่ส่งคำสั่งผิด ข้อจำกัดที่เหลือคือความครอบคลุมชูโป้งขวาใน validation และการยืนยันผลครบระบบก่อนเปลี่ยนรุ่นใช้งาน
