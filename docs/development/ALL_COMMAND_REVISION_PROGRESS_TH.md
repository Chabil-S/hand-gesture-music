# แก้ความลื่นของท่าคำสั่ง: ความคืบหน้า 2026-10-05

ขยายเกณฑ์ validation ก่อนเริ่มค้นหารุ่นรอบนี้: ทั้งสองมือ ทุกคำสั่งรับถูกอย่างน้อย 95% รายเฟรม ต้องออกตรงคำสั่งครั้งเดียวต่อคลิป ภายใน 1.5 วินาทีหลังเฟรมแรก ไม่มีคำสั่งจากแบมือ/สามนิ้ว และท่า neutral ต้องรับเป็น neutral จริงอย่างน้อย 95% ไม่ใช้ uncertain ที่ถูกนับเป็น neutral ในคะแนน classification มาปลดล็อก

เพิ่มการต่อคลิปคำสั่ง -> neutral ที่โมเดลทำนายจริง -> คำสั่งเดิม ต้องได้ตรงคำสั่งสองครั้ง นี่เป็นการต่อคลิปเพื่อวินิจฉัย ไม่ทดแทนการทดสอบการเปลี่ยนท่ากล้องสด เวลา 1.5 วินาทีเป็นข้อกำหนดทางวิศวกรรมสำหรับคลิปค้างท่า ไม่ใช่เวลา Apple Music หรือเวลาจากข้อความที่ผู้ใช้ต้องตอบสนอง

เพิ่มผู้สมัคร Combined Logistic C=0.1/1/10 ที่ใช้ระยะคู่จุดเดิม 210 ค่า ร่วมกับมุม/ระยะ 23 ค่า ไม่ใช้เกณฑ์นิ้วโป้งที่เขียนเอง รวมกับผู้สมัครเดิมเป็น 18 แบบ เกณฑ์คะแนน 5 ค่า รวม 90 การเทียบ validation ฝึกเฉพาะ train และไม่ใช้ข้อมูลเปรียบเทียบสดเป็นข้อมูลฝึก เพราะยังไม่มีป้ายจริงรายเฟรม

**ไม่มีผู้สมัครผ่านครบ** จึงไม่เปิด test รอบนี้ ไม่สร้างหรือเปิดใช้โมเดลใหม่ ตัวชี้ยังเป็น `models/20261004_221121` เกณฑ์ 0.80 ผลรายผู้สมัครเก็บใน `outputs/three_finger_validation_attempt.json` ภายในเครื่อง

ตัวอย่างความขัดกัน: Combined Logistic C=1 เกณฑ์ 0.60/0.80 รับนิ้วโป้ง validation ได้ครบทั้งสองมือและผ่านการต่อคลิปปล่อย แต่สามนิ้วมือซ้ายเกิดคำสั่ง 2 ครั้ง จึงถูกปฏิเสธ ส่วน Joint Logistic C=1 เกณฑ์ 0.80 ไม่มีคำสั่งสามนิ้ว แต่รับนิ้วโป้งขวา 62/79 เฟรมและมีคำสั่งซ้ำในคลิปค้างนิ้วโป้ง จึงไม่ผ่าน ไม่ลดเกณฑ์หรือผ่อนกฎเพื่อให้ได้รุ่นใหม่

## ข้อมูลที่ต้องเพิ่ม

เปิด `D:\hand-gesture-music\outputs\collect_commands_varied_angles.cmd`

1. ปิดหน้าทดลองเปรียบเทียบหรือแอปที่ใช้กล้องอยู่ แล้วกดเปิดกล้องในตัวเก็บข้อมูล
2. เริ่มมือขวา เก็บ 5 รอบ รอบละ 4 ท่า: กำมือ, V พับโป้ง, นิ้วโป้ง, ไม่สั่งงาน ช่วงละ 12 วินาที
3. ทำตามคำแนะนำหน้ามือ/หลังมือของแต่ละรอบ ขณะคงท่าตามป้าย ขยับระยะและมุมที่ใช้งานจริง โดยเฉพาะนิ้วโป้งที่รุ่นใหม่รับยาก ช่วงไม่สั่งงานให้ทำตามคำแนะนำแบมือ/ชี้นิ้วเดียว/ผ่อนคลายบนหน้าจอ
4. เมื่อครบมือขวา กดปุ่มเก็บอีกข้าง แล้วใช้มือซ้ายครบอีก 5 รอบ ใช้มือตามที่เลือกจริงตลอด session
5. เมื่อครบทั้งสองข้าง แจ้งว่า “เก็บท่าคำสั่งครบแล้ว”

รวม 40 ช่วง หรือเนื้อหาท่า 8 นาที บวกเวลาเตรียมและกดปุ่มประมาณ 10–12 นาที ไม่ต้องเก็บสามนิ้วซ้ำรอบนี้ ข้อมูลสามนิ้วเดิมยังคงอยู่

ข้อมูลใหม่มี session แยก ไม่แก้ข้อมูลเก่า เก็บเฉพาะพิกัดในเครื่อง แบ่งทั้งรอบเป็น train/train/train/validation/test ตามแผนก่อนเก็บ ไม่มีการส่งเพลง ไม่ใช้ป้าย Left/Right ของตัวตรวจแทนข้างจริง

หลังเก็บครบ ต้องยืนยันข้างมือ ตรวจแฮช/ความครบ แล้วฝึกเลือกจาก train+validation เท่านั้น ก่อนเปิด test ใหม่ท้ายงาน ข้อมูลเปรียบเทียบสดที่เคยวิเคราะห์แล้วไม่เป็น test อิสระรอบถัดไป
