## ข้อจำกัดและขั้นต่อไป

คะแนนรายเฟรมไม่ได้เท่ากับอัตราสั่งเพลงสำเร็จจริง และเฟรมในแต่ละช่วงมีความสัมพันธ์กัน จำนวนเฟรมจึงไม่ใช่จำนวนการทดลองอิสระ
มีผู้ใช้คนเดียว มือขวา 1 session และมือซ้าย 1 session สภาพใกล้กัน จึงยังสรุปผลข้ามคนหรือแสงอื่นไม่ได้ ไม่มีป้ายหน้ามือ/หลังมือให้รายงานคะแนนแยก
กลุ่ม neutral ยังมีเพียงท่าอื่นที่เก็บ ไม่ครอบคลุมท่าที่ไม่รู้จักทุกแบบ คะแนนสูงก็อาจสั่งผิดเมื่อเจอท่าใหม่
หน้าทดลองเริ่มในโหมดดูผล ไม่ส่งเพลง ต้องกดเริ่มควบคุมก่อน ยืนยันท่า 0.6 วินาทีและปล่อยเป็น neutral หรือเอามือออก 0.35 วินาทีก่อนคำสั่งถัดไป
ต้องทดสอบสั่งเพลงจริงแยก: แต่ละคำสั่ง มือซ้าย/ขวา ค้างท่า ปล่อยท่า ไม่เห็นมือ และท่าอื่น พร้อมบันทึกคำสั่งผิด/ซ้ำและผลเครื่องเล่น

อ้างอิงวิธีประเมิน: https://scikit-learn.org/stable/modules/cross_validation.html

## การแก้ท่าสามนิ้ว

เลือกโมเดลและเกณฑ์คะแนนจาก validation เท่านั้น ต้องไม่มีคำสั่งสามนิ้วผ่านตัวตรวจท่าค้าง และรับ V ครบทุกคลิปพร้อมรับรายเฟรมอย่างน้อย 95% แยกข้าง ก่อนเปิด test
ชุด test ท่าเดิมเคยประเมินแล้ว จึงเป็นการตรวจการถดถอย ส่วน test สามนิ้วเป็นชุดใหม่ ไม่ใช่ชุดทดสอบใหม่ของทุกท่า
validation left: สามนิ้วสั่งผิด 6/236 เฟรม; รับ V 80/80 เฟรม
validation right: สามนิ้วสั่งผิด 0/153 เฟรม; รับ V 79/79 เฟรม
test left: สามนิ้วสั่งผิด 1/238 เฟรม; รับ V 77/77 เฟรม
test right: สามนิ้วสั่งผิด 0/150 เฟรม; รับ V 79/80 เฟรม

## รูปมือและขอบเขต test รุ่นนี้

ตัวจำแนกที่เลือกใช้ cosine มุมข้อนิ้ว 10 ค่า และระยะปลายนิ้ว 13 ค่า ที่คำนวณจากพิกัดเดิม แล้วฝึก Logistic Regression จาก train ไม่ใช้เกณฑ์นิ้วโป้งที่เขียนเอง
test ใหม่หลายมุมมี 233 เฟรมสามนิ้วจากสาม session อ่านเป็นไม่สั่งงานครบ 233/233 ส่วน test สามนิ้วรอบแรกที่เคยประเมินแล้วเป็น regression: ยังมีผิด 1/155 เฟรม แต่ไม่ยาวพอเกิดคำสั่ง
เล่นคลิป test ทั้งหมดผ่าน GestureGate เดิม: ไม่มีคำสั่งผิดใน 13 คลิป; คำสั่งจริงแต่ละท่าเกิดหนึ่งครั้งทั้งสองข้าง ยังไม่ได้ทดลองกล้องสดกับรุ่นใหม่นี้
