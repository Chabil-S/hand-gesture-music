# ผลชุดเก็บหลายมุมใหม่

ข้อมูลครบ 48 ช่วงที่ผ่านเกณฑ์ รวม 3,771 ตัวอย่าง: ขวา 1,885 และซ้าย 1,886 ครบ 6 มุม × 4 ท่าต่อมือ ทุกช่วงใหม่เป็น train ตามแผนก่อนเก็บ ไม่พบข้อผิดพลาดแฮช จำนวนแถว พิกัด หรือเวลา ขวามีหนึ่งช่วงไม่ผ่านซึ่งยังเก็บต้นฉบับไว้ แต่ไม่นำเข้าฝึก

ชุดใหม่: 20261005_185802_f54af187 (ขวา), 20261005_190655_a2a565fb (ซ้าย) ข้างมืออิงการยืนยันของผู้ใช้ตามแผนขวาแล้วซ้าย ไม่อิงป้ายตัวตรวจ

ฝึก 31 รูปแบบโมเดล เปรียบเทียบเกณฑ์คะแนน 5 ค่า รวม 155 คู่ ไม่มีคู่ใดผ่านเงื่อนไขความถูกต้องของคำสั่งทั้งหมด จึงไม่เผยแพร่รุ่นทดลองใหม่ ไม่เปิด test และไม่เปลี่ยนรุ่นควบคุมเพลง

## รุ่นที่คะแนนรวมสูงสุด

FingerReach SVC RBF C=1 เกณฑ์ 0.7 (0.8 ได้คะแนนรวมเท่ากัน) ผลต่อไปนี้เป็น validation สำหรับพัฒนา ไม่ใช่ผลทดสอบอิสระ:

| ท่า | ขวา | ซ้าย |
|---|---:|---:|
| กำมือ | 158/158 (100%) | 237/238 (99.6%) |
| V | 159/159 (100%) | 160/160 (100%) |
| ชูโป้ง | 142/158 (89.9%) | 152/155 (98.1%) |
| ไม่สั่งงานปกติ | 150/160 (93.8%) | 157/157 (100%) |
| สามนิ้ว: คำสั่งผิดหลังผ่านการค้างท่า | 0 ครั้ง | 2 ครั้ง |

ทุกคลิปคำสั่งออกคำสั่งถูกหนึ่งครั้ง ระยะยืนยันสูงสุด 1.219 วินาที แต่ไม่ผ่านสามนิ้วซ้าย ชูโป้งขวา และท่าไม่สั่งงานขวา

มี 7 คู่ที่ไม่ส่งคำสั่งผิดจากสามนิ้วและ neutral ทั้งสองมือ แต่ยังไม่ผ่านเงื่อนไขอื่น คู่ที่คะแนนดีที่สุดในกลุ่มนี้คือ Joint Logistic C=10 เกณฑ์ 0.85: ชูโป้งขวาเหลือ 117/158 (74.1%) และ neutral ขวา 123/160 (76.9%) จึงยังไม่เหมาะนำไปใช้

## สิ่งที่ข้อมูลใหม่ช่วยและสิ่งที่ยังติด

ข้อมูลสมดุลหลายท่าช่วยกำมือในชุดตรวจเดิมได้มาก แต่ยังไม่แก้การแยกชูโป้งขวาและท่าสามนิ้วให้ผ่านพร้อมกัน การเพิ่มตัวอย่างคำสั่งทำให้สัดส่วนข้อมูลท่าไม่สั่งงานชนิดสามนิ้วลดลง; นี่เป็นเหตุที่เป็นไปได้ ไม่ใช่สาเหตุที่พิสูจน์แล้ว ผลนี้จึงไม่สนับสนุนการเพิ่มรูปคำสั่งอย่างเดียวต่อไปโดยไม่ตรวจสมดุลของท่าอื่น

คลิปกำมือซ้ายเดิมที่ยังสงสัยยังอยู่ใน validation ไม่ตัดหรือเปลี่ยนป้ายเพื่อให้คะแนนผ่าน ส่วนคลิปยืนยันกำมือซ้ายใหม่อยู่ใน validation ด้วย จึงห้ามเทียบตัวเลขรวมซ้ายกับรายงานรุ่นก่อนโดยถือว่าจำนวนตัวอย่างเท่ากัน

ขั้นต่อไปควรทดลองถ่วงน้ำหนักข้อมูลฝึกโดยตรวจทั้งสามนิ้วและทุกคำสั่งด้วยเกณฑ์เดิม ก่อนขอเก็บเพิ่ม หากได้รุ่นที่ผ่านจึงตรวจสดใหม่ รุ่นทดลอง 20261005_163211 และรุ่นใช้งานจริงยังคงเดิม

ตรวจแล้วว่าตัวชี้รุ่นใช้งานจริงและประวัติการเปิด test ไม่เปลี่ยน ตรวจตรรกะประเมินการค้าง/ปล่อยและการแยกผลเฟรมจากคำสั่งจริงผ่าน ข้อมูลดิบและโมเดลส่วนตัวไม่อยู่ใน commit
