# ทดลองรุ่นเก่ากับรุ่นใหม่พร้อมกัน

เปิด `D:\hand-gesture-music\outputs\compare_baseline_models.cmd` ปิดหน้าควบคุมเพลงหรือหน้าที่ใช้กล้องเดิมก่อน

1. กด **เปิดกล้อง** แล้วตรวจว่ามีจุดบนมือ
2. อ่านท่าและข้างมือที่ระบุ แล้วกด **เริ่มช่วงทดสอบ**
3. ช่วงเตรียมให้แบมือ 3 วินาที จากนั้นทำท่าตามป้าย 4 วินาที แบมือ 3 วินาที ทำท่าเดิมอีก 4 วินาที และแบมืออีก 3 วินาที ตามข้อความบนจอ
4. กดเริ่มช่วงถัดไปเมื่อพร้อม จนครบ 10 ช่วง: กำมือ, V, นิ้วโป้ง, แบมือ, สามนิ้ว อย่างละสองข้าง ใช้มุมแบบที่เคยรู้สึกว่ารับยาก
5. เมื่อครบ ส่งข้อความ **ทดสอบครบแล้ว** เพื่อให้อ่านผลในเครื่องและวิเคราะห์

ถ้าป้ายเป็นแบมือหรือสามนิ้ว ช่วง “ทำท่า” ให้คงท่านั้น ส่วนช่วง “ปล่อยท่า” ให้แบมือ ทุกช่วงเป็นคำสั่งจำลอง ไม่ต้องเปิด Apple Music

หน้าจอแสดงรุ่นเก่าเกณฑ์ 0.60 รุ่นใหม่เกณฑ์ 0.80 และรุ่นใหม่เกณฑ์ 0.60 ทั้งหมดอ่านเฟรมกล้องเดียวกัน แยกการเลือกมือและตัวตรวจค้างท่าเหมือนแอปจริง ไม่มีการส่งเพลงหรือเปลี่ยนโมเดลที่ใช้งาน

ข้อมูลบันทึกใน `outputs/data/live_comparison/<session>/`: พิกัดมือทุกมือ ขนาดเฟรม เวลาจับภาพ ท่า/มือที่สั่งให้ทำ ผลจำแนก คะแนน สถานะค้าง/ปล่อย และคำสั่งจำลองของแต่ละรุ่น ไม่บันทึกรูปหรือเสียง ไม่อัปโหลด และไม่นำไปฝึกอัตโนมัติ ป้ายเป็นท่าที่ขอให้ทำ ไม่ใช่ป้ายจริงรายเฟรมที่ตรวจโดยมนุษย์ จึงต้องเผื่อเวลาคนเปลี่ยนท่า

หากกล้องค้างเกิน 0.3 วินาทีหรือหน้าต่างปิดก่อนครบ ช่วงนั้นบันทึกเป็น incomplete และต้องลองช่วงเดิมใหม่ ข้อมูลที่หยุดก่อนครบยังคงเก็บอยู่ หากปิดแล้วเปิดใหม่จะสร้าง session ใหม่

ตรวจเครื่องมือแล้ว: ใช้โมเดลจริง ทดสอบทำท่า/ค้าง/ปล่อยแล้วสั่งอีกครั้ง ตรวจขอบเขตเวลาแต่ละช่วง และเปิดหน้าต่างโดยไม่เปิดกล้อง ตัวชี้โมเดลใช้งานเดิมไม่เปลี่ยน
