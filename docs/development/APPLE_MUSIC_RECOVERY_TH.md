# Apple Music โหลด Home ไม่ได้และข้ามเพลงรัว

## ผลตรวจและการกู้ครั้งนี้ — 4 ตุลาคม 2026

Apple Music for Windows รุ่น 1.1540.23042.0 แสดง “An unknown error has occurred” ที่ Home และเมื่อเล่นเพลย์ลิสต์ข้ามเพลงอย่างรวดเร็ว ผู้ใช้แจ้งว่า restart เครื่องแล้วยังเป็น

ตอนตรวจครั้งแรกไม่มี Python/Pythonw หรือโปรแกรมท่ามือทำงาน บันทึก ETL ของ Apple Music ในเครื่องพบ StoreMescalSessionCert error 7504, MediaAPI error 7502 และ “Error initializing Mescal session / Invalid data received” จึงตรวจไปที่แคชไฟล์ตั้งค่าการลงลายเซ็นคำขอของแอป

พบ `setupCert[1].xml` ภายใต้ `%LOCALAPPDATA%\Packages\AppleInc.AppleMusicWin_nzyj5cx40ttqa\AC\INetCache` ขนาด 2,171 bytes เริ่มด้วย gzip magic `1f8b0800` เมื่อคลาย gzip ได้ XML ที่ parse ได้ขนาด 3,257 bytes การเปรียบเทียบนี้มาจากไฟล์ในเครื่อง ไม่ใช่การยืนยันว่า Apple Music ทุกเครื่องมีสาเหตุเดียวกัน

ปิดแอป สำรองไฟล์ดังกล่าวและตรวจ SHA-256 ว่าสำเนาตรงกัน จากนั้นเอาเฉพาะรายการแคชนั้นออกเพื่อให้แอปดาวน์โหลดใหม่ ไม่ reset แอป ไม่ออกจากบัญชี และไม่แก้ library/account/DRM stores หลังเปิดใหม่พบไฟล์ XML ปกติ 3,257 bytes และ Home โหลดข้อมูลได้ แอปค้างช่วงโหลด Home ครั้งแรก จึงปิดเฉพาะโปรเซสที่ Not Responding แล้วเปิดใหม่อีกครั้ง

ทดสอบกด Play ของเพลย์ลิสต์หนึ่งครั้ง จากนั้นอ่าน Windows media session ทุก 2 วินาทีรวม 20 วินาที: อยู่เพลงเดียวตลอด สถานะ PLAYING ทุกครั้ง และตำแหน่งเดินจาก 75 ถึง 95 วินาที ไม่มีการส่งคำสั่ง next ระหว่างการตรวจ ข้อมูลนี้ยืนยันการกู้ครั้งนี้ในช่วงที่ตรวจ ไม่รับประกันว่าจะไม่เกิดซ้ำ

สำเนาแคชและบันทึกวิเคราะห์อยู่ใน `work/` ของ workspace ต้นฉบับใน C เก็บในเครื่องเท่านั้น ไม่อัปโหลดแคช บันทึก ETL หรือข้อมูลเพลงส่วนตัวขึ้น GitHub

## ถ้าเกิดซ้ำก่อนเดโม

1. ปิดโปรแกรมท่ามือแล้วลองเพลงใน Apple Music โดยตรง แยกปัญหาแอปจากการรับท่า
2. ตรวจว่าหน้า Home มี error แบบเดิม และตรวจหลักฐานใหม่ก่อนสรุปว่าเป็นแคชแบบเดิม
3. หากยืนยันไฟล์ตั้งค่าแคชผิดรูปแบบแบบครั้งนี้ ให้ปิด Apple Music ก่อน สำรองรายการแคชเฉพาะนั้นแล้วให้แอปดาวน์โหลดใหม่
4. เปิดแอป ทดสอบ Home และเพลงเดิมเดินต่อเนื่องก่อนเริ่มระบบท่ามือ

อย่าใช้วิธีลบคลังเพลงหรือ reset บัญชีจากอาการอย่างเดียว วิธีครั้งนี้รักษาข้อมูลหลักและสามารถคืนไฟล์แคชจากสำรองได้
