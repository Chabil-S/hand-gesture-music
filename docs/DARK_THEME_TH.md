# การเปลี่ยนธีม

1. เปิดหน้า Settings / ตั้งค่า
2. กด **Ctrl+Shift+L** เพื่อแสดงตัวเลือกภาษาและธีมที่ซ่อนไว้
3. กด **ธีมมืด / Dark theme** เพื่อใช้สีดำ–ขาว หรือ **ธีมสว่าง / Light theme** เพื่อกลับสีครีม–ฟ้าเดิม
4. กด **Ctrl+Shift+L** อีกครั้งเพื่อซ่อน ตัวเลือกจะซ่อนเองเมื่อเปลี่ยนหน้า

ธีมมีผลทันทีทั้งหน้ากล้อง หน้าเพลง หน้าตั้งค่า และหน้าตัวเลือกท่าควบคุม ระบบจำธีมไว้เมื่อเปิดใหม่ใน `outputs/ui_preferences.json` ร่วมกับภาษา การเปลี่ยนธีมไม่เปลี่ยนโมเดล คะแนนรับท่า สถานะกล้อง หรือสถานะเริ่ม/พักการควบคุม
