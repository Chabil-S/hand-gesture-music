# การแก้ท่าโป้ง–ชี้–กลาง

## รุ่นที่เปิดใช้

เปิดใช้ `models/20261004_221121`: **Joint Logistic C=1, threshold 0.8** ใช้ cosine มุมข้อนิ้ว 10 ค่าและระยะปลายนิ้ว 13 ค่า คำนวณจากพิกัดที่ปรับขนาดฝ่ามือ แล้วฝึกตัวจำแนกจาก train เป็นการเรียนรู้รูปมือ ไม่ใช่เปิดตัวกรองนิ้วโป้งแบบเก่า

ข้อมูลสำหรับรุ่นนี้ train 2,744 / validation 1,022 / test 1,022 เฟรม คนเดียว รวม 7 session ที่ครบ เก็บไฟล์สอง session ที่ไม่ครบไว้ แต่ยกเว้นจากการฝึกอย่างชัดเจน: `20261004_213132_79f24dc6`, `20261004_214424_3624e47e`

| ผล | สามนิ้วรายเฟรมที่ยังอ่านเป็นคำสั่ง | คำสั่งจากคลิปสามนิ้วเมื่อใช้ตัวตรวจท่าค้าง |
|---|---:|---:|
| validation ทั้งสองข้าง | 6/389 | 0 ใน 5 คลิป |
| test หลายมุมใหม่ ทั้งสองข้าง | 0/233 | 0 ใน 3 คลิป |
| test สามนิ้วรอบแรกที่เคยประเมินแล้ว | 1/155 | 0 ใน 2 คลิป |

V ใน validation รับ 159/159 เฟรม ส่วน test ท่าเดิมรับ 156/157 หลังใช้ threshold ยืนยัน “ถัดไป” ได้หนึ่งครั้งต่อคลิปทั้งสองข้าง ชุด test ท่าเดิมเป็น regression ไม่ใช่ผลจากข้อมูลใหม่

คลิป test รวม 13 คลิปผ่าน GestureGate: ไม่มีคำสั่งผิด ท่ากำมือ V และโป้งเกิดคำสั่งที่ถูกต้องหนึ่งครั้งทั้งสองข้าง ไม่ส่งคำสั่งเพลงจริงในการ replay และไม่แทนการเปลี่ยนท่าต่อเนื่องหน้ากล้อง

เลือกตัวจำแนกและ threshold จาก validation ก่อนเปิด test หลายมุมใหม่ ในรอบตรวจขั้นต้นไม่มีโมเดลผ่านเกณฑ์ศูนย์เฟรมผิด ต่อมาปรับการเลือกให้ตรงพฤติกรรมการสั่งเพลง: ต้องไม่มีคำสั่งจากสามนิ้วหลังคงท่า 0.6 วินาที, V ต้องยืนยันได้หนึ่งครั้งทุกคลิป และรับ V รายเฟรม >=95% แยกข้าง พร้อมรายงานเฟรมผิดไว้ครบ ระยะ hold/release/max-gap ไม่ได้เปลี่ยนหรือปรับจาก test

ตัวเลือกที่ตรวจจาก validation มี 15 ตัวจำแนกและ threshold 0.6/0.7/0.8/0.85/0.9 เป็นการพัฒนาโดยใช้ validation หลายรอบ ผล test ใหม่ครอบคลุมเฉพาะท่าสามนิ้ว ไม่ใช่การพิสูจน์ความแม่นยำข้ามคนหรือสภาพแสงอื่น

ปิดหน้าทดลองเก่าแล้วเปิด `outputs/เปิดระบบควบคุมเพลง.cmd` จากโฟลเดอร์ D เพื่อโหลดรุ่นใหม่ เริ่มในโหมดดูผลและลองสามนิ้ว/V ทั้งสองข้างก่อนเริ่มควบคุมเพลง **การลองกล้องสดรุ่นนี้ยังรอผู้ใช้ทดสอบ**

รายละเอียด: [รายงานรุ่นใหม่](MODEL_REPORT_V2_TH.md), [manifest และแฮชโมเดล](MODEL_V2_MANIFEST.json)

## รอบแรก: ยังไม่เปิดใช้

เพิ่ม neutral สามนิ้วที่ผู้ใช้เก็บครบทั้งซ้ายและขวา 467 เฟรม แบ่งทั้งรอบ: train 157, validation 155, test 155 ไม่ย้ายเฟรมข้ามชุด ชุดขวา `20261004_213132_79f24dc6` เก็บไม่ครบและเริ่มชุดขวาใหม่ จึงยกเว้นอย่างชัดเจนจากการฝึก โดยยังรักษาไฟล์ดิบทุกชุด

เปรียบเทียบเฉพาะ validation: โมเดลเดิมสั่งผิด 145/155 เฟรมสามนิ้ว รุ่นทดลอง `20261004_213614` (Logistic C=1, threshold 0.6) สั่งผิด 0/155 และรับ V 159/159 โมเดลและเกณฑ์คะแนนถูกเลือกก่อนประเมิน test

ผล test สามนิ้วใหม่ยังสั่งผิด 30/155 (ซ้าย 20/78 ขวา 10/77) ท่า V เดิมรับ 157/157 ผล test ท่าเดิมเป็นการตรวจการถดถอย เพราะเคยประเมินแล้ว ไม่ใช่ชุดทดสอบใหม่ โมเดลทดลองยังไม่เพียงพอสำหรับเปิดใช้ จึงคืนตัวชี้โมเดลใช้งานไปที่ `20261004_171415` และรักษา artifacts รุ่นทดลองไว้

## การเก็บเพิ่ม

เปิด `outputs/เก็บสามนิ้วหลายมุม.cmd` ข้างละ 5 ช่วง: train หน้าฝ่ามือ, train หลังมือ, train มุมผสม, validation มุมผสม, test ทำใหม่อิสระ ทุกช่วงคงโป้ง–ชี้–กลาง 12 วินาที สลับข้างด้วยปุ่มในโปรแกรม มีคำแนะนำมุมบนหน้าจอ แต่ไม่มีป้ายมุมรายเฟรม จึงไม่สามารถรายงานความถูกต้องแยกหน้ามือ/หลังมือได้

ชุด test สามนิ้วรอบแรกจะรักษาเป็นผลการตรวจการถดถอย ไม่ใช้เลือกการปรับครั้งถัดไป แยกผล test ตาม session เพื่อระบุชุดใหม่ชัดเจน

## การฝึกและเปิดใช้

เมื่อพบข้อมูลสามนิ้วจะเปิดเงื่อนไขตรวจ revision อัตโนมัติ คำสั่งตัวอย่าง: `outputs/train_gestures.py --require-three-finger-validation --exclude-session 20261004_213132_79f24dc6 --exclude-session 20261004_214424_3624e47e` ฝึกจาก train และเลือกโมเดล+threshold ที่ผ่าน validation: สามนิ้วไม่เกิดคำสั่งผ่าน GestureGate เดิม, V ยืนยันได้หนึ่งครั้งทุกคลิป และรับ V รายเฟรม >=95% แยกข้าง หากไม่มีตัวเลือกผ่านจะหยุดโดยไม่ประเมิน test หรือเปลี่ยนโมเดล

รุ่นทดลองบันทึกแยกเพื่ออ่านรายงาน ค่าเริ่มต้นสำหรับ revision จะไม่เปลี่ยนโมเดลใช้งาน ต้องเปิดใช้โดยตั้ง `latest_model.json` หลังตรวจผลและขอบเขต หรือระบุ `--activate` อย่างชัดเจนในงานที่เตรียมเปิดใช้ โมเดลเดิมและข้อมูลดิบไม่ถูกเขียนทับ

คะแนนเหล่านี้เป็นรายเฟรมจากคนเดียว เฟรมสัมพันธ์กัน ยังต้องลองกับกล้องสด ท่าสามนิ้ว V สองข้างและหลายมุม ก่อนกล่าวว่าแก้ปัญหาในสภาพใช้งานจริงสำเร็จ

ใช้ `tools/replay_gesture_clips.py --model-directory models/<version> --session <session_id>` เพื่อตรวจคำสั่งแบบออฟไลน์ของรุ่นที่เลือกแล้ว ไม่ใช้แทนการทดสอบเพลงจริง
