# หน้าควบคุมเพลงสองมุมมอง

เปิด `D:\hand-gesture-music\outputs\start_music_controller.cmd` หลังเปิด Apple Music และเริ่มเพลงแล้ว แอปเริ่มในโหมดดูผลและยังไม่เปิดกล้อง

## จับท่าทาง

- กด **เปิดกล้อง** เพื่อดูภาพ จุดข้อต่อ และกรอบสีเขียวของมือที่รับคำสั่ง
- ภาพกล้องขยายตามพื้นที่หน้าต่าง รวมถึงเมื่อเปิดเต็มจอ โดยรักษาสัดส่วนภาพและไม่ตัดขอบ คำแนะนำท่ารวมไว้สองบรรทัดใต้กล้อง และแถบเพลงแสดงข้อมูลแบบกระชับเพื่อเพิ่มพื้นที่ภาพ
- ด้านขวาแสดงท่าที่ตรวจพบ คะแนนโมเดล และการนับเวลาค้างท่า คะแนนนี้ไม่ใช่ค่าความแม่นยำของทั้งระบบ
- กด **เริ่มควบคุมเพลง** แล้วเอามือออกตามเวลาปล่อยมือก่อนเริ่มทำท่าคำสั่ง
- กำมือ = เล่น/พัก, V นิ้วชี้–กลางและพับโป้ง = ถัดไป, ชูโป้ง = ก่อนหน้า
- ค้างท่าไม่ส่งซ้ำ ต้องเอามือออกหรือทำท่าไม่สั่งงานก่อนท่าถัดไป
- กด **พักการควบคุม** เพื่อกลับโหมดดูผล หรือ **ปิดกล้อง** เพื่อหยุดกล้องและการควบคุมด้วยมือ

## กำลังฟัง

หัวข้อใช้ **Now playing** โดยไม่สร้างชื่อ playlist ขึ้นเอง แถบเพลงย่อในหน้าจับท่าทางแสดงชื่อเพลง ศิลปิน/อัลบั้ม สถานะ และเวลาเพลง

- เมนู **กำลังฟัง** เน้นภาพปก ชื่อเพลง ศิลปิน สถานะเล่น/พัก และเวลาจาก Apple Music พร้อมกล้องขนาดย่อม
- สลับระหว่าง **จับท่าทาง** กับ **กำลังฟัง** ได้โดยไม่รีเซ็ตจังหวะรับท่าและไม่เปลี่ยนโหมดควบคุม
- ปุ่ม **ก่อนหน้า / เล่น–พัก / ถัดไป** สั่งงานทันทีเมื่อ Apple Music อนุญาต แม้อยู่ในโหมดดูผลของท่ามือ
- ปุ่มเพลงพักไว้ขณะคำสั่งก่อนหน้ายังอยู่ในคิว และเมื่อไม่ได้เชื่อมต่อ
- ข้อมูลเพลงอ่านอัตโนมัติแยกจากกล้อง ประมาณทุก 1.5 วินาที; ขณะโหลดภาพปกหรือบริการตอบช้าอาจนานกว่านี้ การอ่านข้อมูลไม่ส่งคำสั่งเล่นหรือข้ามเพลง
- หาก Apple Music ไม่ส่งภาพปก จะใช้ภาพพื้นธีมและระบุว่ายังไม่มีภาพปก หากไม่มีเวลาเพลง จะระบุว่าไม่มีข้อมูลระยะเวลาแทนการสร้างเวลาขึ้นเอง
- **อ่านสถานะ Apple Music** ใช้ตรวจการเชื่อมต่อด้วยตนเอง เปิด Apple Music และเริ่มเพลงก่อนหากยังไม่พบ session

## ตั้งค่า

เมนู **ตั้งค่า** รวมตัวเลือกเดิมไว้ในหน้าหลัก ไม่ต้องเปิดหน้าต่างแยก

| ค่า | วิธีปรับและผล |
|---|---|
| คะแนนขั้นต่ำรับท่า (%) | เลื่อนแถบหรือพิมพ์ตัวเลข มากกว่า 0 ถึง 100; สูงขึ้นจะรับท่ายากขึ้นแต่ต้องมั่นใจมากขึ้น |
| เวลาค้างท่า (วินาที) | เวลาที่ต้องค้างท่าก่อนส่งคำสั่ง; ต้องมากกว่า 0 |
| เวลาปล่อยมือ (วินาที) | เวลาของท่าไม่สั่งงาน/ไม่มีมือ ก่อนรับคำสั่งใหม่; ต้องมากกว่า 0 |
| ช่วงภาพขาดที่ยอมรับ (วินาที) | อยู่ใน **การตั้งค่าเพิ่มเติม**; ภาพเว้นเกินนี้เริ่มนับเวลาค้างท่าใหม่; ต้องมากกว่า 0 |

กด **บันทึกและใช้ค่า** เพื่อบันทึกลง `outputs/live_settings.json` แอปจะพักการควบคุม ยกเลิกคำสั่งที่ยังไม่เริ่มส่ง และกลับหน้ากล้องในโหมดดูผล คำสั่งที่เริ่มส่งแล้วอาจทำงานจนจบ

**คืนค่าที่รุ่นเคยทดสอบ** เติมค่าจากรุ่นที่ใช้ลงช่องกรอก ต้องกดบันทึกเพื่อใช้จริง ค่านี้อาจต่างจากค่าขณะใช้งานของคุณ

การเปิดหน้าตั้งค่าอย่างเดียวไม่พักการควบคุม หากต้องการหยุดรับคำสั่งระหว่างปรับ ให้กดพักการควบคุมก่อน

ช่องคะแนนและแถบเลื่อนแสดงค่าเดียวกัน เลื่อนด้วยเมาส์หรือกด Tab ไปที่แถบแล้วใช้ลูกศรซ้าย/ขวาได้ พิมพ์ค่าทศนิยมในช่องตัวเลขได้ตามเดิม สถานะควบคุมและเวลาค้าง/ปล่อยมืออยู่ในกลุ่มเดียวกับปุ่มควบคุมของแต่ละมุมมอง

## ท่าควบคุมร่วมกัน

จีบปรับเสียงและแบมือพัก/เริ่มใช้งานร่วมกับท่าเพลงในโหมดเดียว เปิดไว้เป็นค่าเริ่มต้น ไม่ต้องเข้าโหมดทดลอง หากต้องการปิดบางท่า ไปที่ **ตั้งค่า → ท่าควบคุม** ตัวเลือกบันทึกแยกจากค่ารับท่าและจำเมื่อเปิดโปรแกรมใหม่ อ่านวิธีใช้ใน [EXTRA_GESTURES_GUIDE_TH.md](EXTRA_GESTURES_GUIDE_TH.md)

ทุกครั้งที่เปิดโปรแกรมยังเริ่มในโหมดดูผล เปิดกล้องแล้วกดเริ่มควบคุม หรือเอามือออกก่อนแล้วแบมือค้าง 1.2 วินาที เมื่อจบท่าจีบให้ปล่อยมือ/ทำท่าไม่สั่งงานตามเวลาปล่อยมือ ก่อนกำมือหรือทำท่าเปลี่ยนเพลง เพื่อกันคำสั่งจากการเปลี่ยนท่า

## ภาษา

เข้า **ตั้งค่า** แล้วกด **Ctrl+Shift+L** เพื่อแสดงปุ่ม **EN / ไทย** ที่ซ่อนไว้ กดชุดปุ่มเดิมหรือออกจากหน้าตั้งค่าเพื่อซ่อนอีกครั้ง วิธีนี้ซ่อนจากหน้าจอปกติ แต่ไม่ใช่ระบบล็อกด้วยรหัสผ่าน กดเพื่อสลับเมนู คำอธิบาย และข้อความสถานะระหว่างสองภาษาได้ทันที โดยไม่รีเซ็ตจังหวะจับท่าหรือช่องตั้งค่าที่กำลังแก้ ภาษาเก็บใน `outputs/ui_preferences.json` แยกจากค่ารับท่าและไม่ส่งเข้า Git ชื่อเพลง ศิลปิน และอัลบั้มแสดงตามข้อมูลจาก Apple Music โดยไม่แปล

ธีมหน้าจอใช้ Merino `#F5EEDD`, Rock Blue `#84B3CE`, Venice Blue `#16587B` ตามดีไซน์ที่เลือก ภาพปกจริงอาจมีสีอื่น หน้าต่างเริ่มที่ 1220×900 และย่อได้ถึง 1080×820

UI นี้ไม่เปลี่ยนไฟล์โมเดล ข้อมูลฝึก เกณฑ์ประเมินรุ่น หรือค่ารับท่าที่บันทึกไว้ จนกว่าคุณจะกดบันทึกการตั้งค่าเอง
