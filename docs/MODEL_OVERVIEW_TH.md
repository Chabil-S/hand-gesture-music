# โมเดลและการประเมิน

## รุ่นใช้งาน

- Weighted FingerReach SVC, RBF kernel, C=10
- Pipeline: FingerReachFeatures → StandardScaler → SVC
- พิกัดมือ 21 จุดแปลงเป็นระยะคู่จุด 210 ค่า ก่อนสร้างคุณลักษณะทางเรขาคณิต 58 ค่า
- คลาส: neutral, next, previous, toggle
- ฝึกด้วย Train 10,065 เฟรม และเลือกจาก Validation 1,734 เฟรม
- ใช้น้ำหนักตัวอย่างในชุดฝึกเพิ่มความสำคัญของท่าสามนิ้วและ neutral
- รุ่นที่ตรึงก่อน Test ใช้คะแนนขั้นต่ำ 80% ค้างท่า 0.6 วินาที และปล่อย 0.35 วินาที
- Model SHA-256: `f9df930a1654287d5c8e47df66e152129161782464e15a3b6017ff6b81a48a7d`

MediaPipe เป็นตัวตรวจตำแหน่งมือสำเร็จรูป ส่วน SVC ฝึกจากข้อมูลท่าทางของโครงการ แบมือและจีบปรับเสียงใช้เรขาคณิตและเวลา ไม่ใช่คลาสเพิ่มเติมของ SVC

## ผล Test ของรุ่นสุดท้าย

ผลบันทึกวันที่ 6 ตุลาคม 2026 โดยใช้ไฟล์โมเดลที่มี hash ข้างต้น ไม่ฝึกหรือปรับรุ่นจากผล Test

| ชุดประเมิน | จำนวนเฟรม | Accuracy ก่อนคะแนนขั้นต่ำ | Accuracy หลังคะแนนขั้นต่ำ 80% |
|---|---:|---:|---:|
| ข้อมูลที่ยังไม่เคยประเมิน | 634 | 93.69% | 91.32% |
| ผลรวม รวมข้อมูลที่เคยใช้ประเมินรุ่นก่อน 1,022 เฟรม | 1,656 | 97.40% | 96.56% |

ควรใช้ชุดที่ยังไม่เคยประเมินเป็นหลักในการอธิบายผลอิสระ ผลรวมมีไว้ดูการทำงานกับข้อมูลเดิมเพิ่มเติม ทั้งสองชุดมาจากผู้จัดทำคนเดียว เฟรมในคลิปเดียวกันสัมพันธ์กัน

การ replay 21 คลิปผ่าน GestureGate: คลิปคำสั่ง 11/12 คลิปส่งคำสั่งถูกต้องครั้งเดียว อีกหนึ่งคลิปส่งซ้ำ; คลิป neutral/สามนิ้ว 9/9 คลิปไม่ส่งคำสั่ง เป็นการเล่นข้อมูลพิกัดบันทึก ไม่ได้ส่งคำสั่งไป Apple Music จึงไม่ใช่อัตราสำเร็จของระบบทั้งชุด

ผลและ predictions รายเฟรมเก็บในเครื่องที่ `outputs/evaluations/current_model_20261006/` ไม่เผยแพร่ข้อมูลผู้เก็บผ่าน repository

## การเปรียบเทียบอัลกอริทึม

รอบพัฒนาที่ใช้ Joint 23 คุณลักษณะ, Train 5,361 และ Validation 1,655 เฟรมเดียวกัน ให้ผลรายเฟรมก่อนใช้คะแนนขั้นต่ำดังนี้:

| อัลกอริทึม | Validation Accuracy | Macro F1 |
|---|---:|---:|
| Logistic Regression, C=1 | 96.98% | 0.9659 |
| Random Forest, 200 ต้น | 94.86% | 0.9422 |
| SVC RBF, C=1 | 97.46% | 0.9716 |

การเปรียบเทียบนี้สนับสนุนการพัฒนาต่อด้วย SVC ภายใต้เงื่อนไขรอบนั้น ไม่ใช่การเปรียบเทียบรุ่น Weighted FingerReach กับตัวเลือกอื่นด้วย 58 คุณลักษณะ และไม่ยืนยันว่า SVC ดีกว่าเสมอ

## การฝึกซ้ำและ artifacts

`outputs/train_gestures.py` เป็น pipeline ฝึกเริ่มต้น ส่วน `tools/train_weighted_diagnostic.py` ใช้ทดลองน้ำหนักข้อมูล และ `tools/activate_reviewed_model.py` ตรวจรุ่นก่อนเปิดใช้ ดูวิธีทดลองย้อนหลังใน `docs/development/`

การทำซ้ำผลเดิมต้องใช้ชุดข้อมูล ป้ายกำกับ รายการตัดข้อมูล น้ำหนัก และรุ่น dependencies ตรงกับรอบที่บันทึกไว้ การ clone repository โดยไม่มี artifacts ไม่ได้สร้างรุ่นสุดท้ายให้อัตโนมัติ ไม่โหลดไฟล์ joblib จากแหล่งที่ไม่เชื่อถือ
